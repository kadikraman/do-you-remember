# Do You Remember?

A mobile quiz app for developers who want to check whether they still know the things they've looked up a hundred times.

Three categories, five random questions each session, no cheating.

## Categories

- **Git Commands** — branches, rebase, stash, reset, cherry-pick
- **HTTP Status Codes** — do you know your 301 from your 302, your 401 from your 403?
- **JavaScript Quirks** — `typeof null`, `0.1 + 0.2`, `[] + {}`, and other classics

## Stack

- Expo SDK 55 / expo-router
- React Native 0.83, React 19, TypeScript
- Reanimated 4 for press animations

## Running locally

```bash
bun install
npx expo run:ios     # iOS simulator
npx expo run:android # Android emulator
```
